为什么要先写清这五项判断？ Why name these five judgments first?

先问这五个问题Ask these five questions first

你要省下的是产出，还是判断？Are you saving output, or judgment?

如果只是让智能体多做一轮，简单循环就够了。Loopora 真正节省的是人类反复回场做的判断：证据够不够、是否假完成、该继续还是转向。 If the only goal is another Agent pass, a simple loop is enough. Loopora saves the repeated human judgment loop: is the evidence real, is this fake done, should the next round continue or redirect?

判断为什么不能只写成提示词？Why is judgment not just a prompt?

因为提示词主要影响下一次回答。可运行的判断必须落到 Loop 契约、角色责任、流程时机和证据规则里，才能在每轮被追问、记录和裁决。 Because a prompt mainly shapes the next answer. Runnable judgment must land in the Loop contract, role responsibilities, run-flow timing, and evidence rules so every round can be questioned, recorded, and judged.

为什么不让模型直接学？Why should the model not just learn this?

这次任务的判断有局部性、时效性和可争议性，不该静默写进模型权重。Loop 让它保持显式、可预览、可修改、可丢弃。 This task's judgment is local, temporary, and debatable. It should not disappear into model weights. A Loop keeps it explicit, previewable, editable, and disposable.

这套判断要不要活过一次聊天？Should this judgment survive one chat?

如果判断只影响当前回复，直接聊天就够了。值得编译成 Loop 的判断，应被运行继承、导出复用，或作为之后审计证据的契约。 If the judgment only shapes this reply, direct chat is enough. A Loop-worthy judgment should be inherited by the run, exported for reuse, or audited later as evidence.

什么时候别开 Loop？When should you not open a loop?

如果下一轮不会产生新证据，或者一次人工复核就能定案，就别开 Loop。没有治理结构和新证据的 Loop 不是收敛器，只是开盲盒。 If another round will not create new evidence, or one human review can settle it, do not open a loop. A loop without governance and new evidence is not convergence; it is a blind box.

如果需要，哪种流程最像这次判断？If it does, which flow matches this judgment?

别把流程当静态规则背。它们是复杂判断的几种可运行形状：这次最先稀缺的是完整路径、根因证据、问题切片、二次修复证据，还是最新基准？ Do not memorize flows as static rules. They are runnable shapes for complex judgment: is this task first missing a complete path, root-cause evidence, a narrowed slice, second-pass repair evidence, or the latest benchmark?
