# Loopora Contracts

These contracts sit below `HUMAN-SHAPED-LOOP.zh-CN.md` and `README.zh-CN.md`. They define what must stay true while the
implementation stays free to shrink.

## Test Asset Governance

Contract tests protect stable claims through one canonical proof layer plus small cross-layer smoke checks. New tests should
reuse the canonical proof instead of restating the same shape in CLI, Web, service, and adapter assertions.

| Stable claim | Canonical proof layer | Secondary smoke layer | Avoid |
| --- | --- | --- | --- |
| v3 Agent envelope shape | `agent_native_v3_helpers.assert_agent_v3_envelope` and Agent Native summary/projection tests | CLI JSON status/actionability checks | Duplicated envelope helpers, treating `raw.legacy` as the v3 contract |
| Agent Native work panel, proof/lifecycle split, submit repair | Agent Native projection/submit-repair contract tests | Plain first-screen actionability and command smoke | Full prose locking, re-deriving proof semantics in CLI tests |
| Adapter managed entries and native guidance | Adapter section/semantic-marker tests for Codex, Claude Code, and OpenCode | Init/check smoke and managed-version tests | Long entry snippets as contracts, adapter-specific copy as proof |

| Runtime verdict and evidence coverage | Runtime verdict/evidence coverage tests | CLI/Web run-detail smoke | Treating process success, todo state, or host trace as task proof |
