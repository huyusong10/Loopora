# Code of Conduct

Loopora is an experimental local-first project, but public collaboration should still be respectful, safe, and evidence-oriented. This code of conduct applies to repository issues, pull requests, reviews, discussions, release notes, and other public project spaces controlled by maintainers.

## Expected Behavior

- Be respectful, specific, and constructive when disagreeing.
- Critique ideas, evidence, risks, and tradeoffs rather than people.
- Keep reports and examples redacted: do not publish secrets, tokens, private logs, private workspace paths, exploit details, or sensitive run artifacts.
- Respect the support, security, governance, and license boundaries documented in [SUPPORT.md](./SUPPORT.md), [SECURITY.md](./SECURITY.md), and [GOVERNANCE.md](./GOVERNANCE.md).
- Help maintainers keep issues and pull requests actionable by naming the affected workflow, stable behavior, evidence, and risk.

## Unacceptable Behavior

- Harassment, threats, personal attacks, discriminatory language, or sustained disruption.
- Publishing private data, credentials, exploit details, or sensitive workspace information in public channels.
- Pressuring contributors or maintainers to bypass security reporting, evidence, review, migration, compatibility, or license/distribution boundaries.
- Repeatedly derailing issues or pull requests after maintainers ask to return to the project scope.

## Reporting And Enforcement

If a conduct concern is also security-sensitive, follow [SECURITY.md](./SECURITY.md) and do not post details publicly. For non-security conduct concerns, contact a maintainer through the least public project channel available, or open a public issue that asks for a private maintainer contact without naming private details.

Maintainers may edit or remove public comments, close or lock discussions, ask participants to step back, or restrict participation when needed to protect the project and its contributors. Enforcement should be proportionate, documented when it can be public, and careful not to expose private or security-sensitive information.

## Scope Limits

This code of conduct governs project spaces controlled by Loopora maintainers. It does not create a support response-time guarantee, license grant, employment relationship, legal process, or moderation promise for third-party Agent hosts, provider services, operating systems, or private projects.
